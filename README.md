## 下单前确认这几件事

1. **计费周期最短多久**，年付比月付便宜多少。这两项直接决定第一年的支出。
2. **续费价和首期价是否一致**。有些商家首期特价、续费回原价，签之前问清。
3. **流量超了会怎样**。限速、停机还是按 GB 计费，三种处理方式对业务的影响完全不同。
4. **退款条件的具体措辞**。写在条款哪一节，覆盖哪些情况。
5. **是否需要身份或支付方式验证**。部分商家用银行卡付款要走完整账号验证。
6. **IPv6 有没有**。依赖 IPv6 的业务这一项是硬门槛。

## 常见问题

**美国 VPS 和美国 VPN 是一回事吗？**
不是。VPS 是一台托管在美国机房的虚拟服务器，你自己装系统、跑网站和应用，有完整 root 权限。VPN 是一层加密通道，用来改变出口 IP 和保护传输。前者是主机，后者是网络服务。

**免费美国 VPS 能用吗？**
谨慎对待。打着免费旗号的服务，常见做法是在带宽、存储、CPU 上设一个很低的限额，超了就要求升级付费，或者靠收集用户信息变现。真要试，先确认对方的公司主体和条款，别把生产环境放上去。

**$4 那档的 20Mbps 会不会太慢？**
一个日均几千 PV 的普通站点，20Mbps 绰绰有余。慢不慢取决于并发下载和视频类流量，静态页面和小 API 几乎感觉不到限制。真跑满了再升档，不用一开始就买贵的。

**机器能自己改配置吗？**
能。内存、CPU、硬盘、带宽、流量、快照数量都在下单页按需选择组合，不是固定套餐二选一。
